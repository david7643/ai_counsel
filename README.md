# 마음결 · 웹 UI MVP

내담자가 AI 대화 예시로 감정을 정리하고, 상담사가 샘플 리포트와 상담 일정을 관리하는 프런트엔드 프로토타입입니다.

## 실행과 화면 분리

각 HTML 파일을 브라우저에서 직접 열 수 있습니다. Node.js, 패키지 설치, 백엔드가 필요하지 않습니다.

| 화면 | 진입 파일 | 로컬 서버 주소 |
| --- | --- | --- |
| 내담자 전용 공간 | `client.html` | `http://127.0.0.1:4173/client.html` |
| 상담사 전용 공간 | `counselor.html` | `http://127.0.0.1:4173/counselor.html` |
| 상담 일정 바로가기 | `counselor.html#schedule` | `http://127.0.0.1:4173/counselor.html#schedule` |

기존 `index.html`도 내담자 화면으로 열립니다. 화면 안에는 역할 전환 버튼이나 다른 역할로 이동하는 링크가 없습니다. 평가할 때 두 주소를 각각 별도 탭으로 열면 됩니다. 역할은 HTML 진입점에서 결정하므로 내담자 페이지의 `#schedule`, 상담사 페이지의 `#chat`처럼 다른 역할의 경로를 입력해도 현재 역할의 첫 화면으로 돌아갑니다. 실제 로그인이나 서버 권한 검증을 구현한 것은 아닙니다.

로컬 HTTP 서버를 사용하려면 프로젝트 폴더에서 실행하세요.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

## 내담자 체험

1. **마음 홈**에서 기분을 선택하면 주간 감정 그래프에 즉시 반영됩니다.
2. **마음 대화**에서 메시지를 보내면 주제에 맞는 준비된 응답이 표시됩니다. Enter는 전송, Shift+Enter는 줄바꿈입니다.
3. **감정 기록**에서 일기를 작성하거나 삭제할 수 있습니다.
4. **나의 마음 리포트**에서 샘플 분석을 읽고 전달 메모를 저장합니다.
5. 공유 항목을 확인하고 체크박스로 동의 과정을 체험합니다. 개인정보와 공유 설정에서 철회할 수 있습니다.

## 상담사와 캘린더 체험

1. **대시보드**에서 내담자 리포트와 오늘의 상담을 확인합니다. 오늘 일정은 캘린더와 같은 데이터를 사용합니다.
2. **내담자 관리 / 대화 분석 리포트**에서 이름·주제로 검색하고 동의된 샘플 리포트를 읽습니다. 서연님은 동의 대기 상태의 예시로 잠겨 있습니다.
3. **상담 일정**에서 월간 캘린더와 선택한 날짜의 상세 일정을 확인합니다. 이전·다음 달, 오늘 이동, 개인·초기·화상 상담 필터를 사용할 수 있습니다.
4. **새 일정 / 이 날짜에 일정 추가**로 내담자, 날짜, 시작 시간, 소요 시간, 상담 유형과 준비 메모를 입력합니다. 리포트에서도 해당 내담자를 미리 선택한 일정 입력창을 열 수 있습니다.
5. 일정의 연필 버튼으로 수정합니다. 날짜를 바꾸면 캘린더도 해당 날짜로 이동합니다. 다른 상담과 겹치는 시간은 입력 중에 안내하고 저장을 막습니다.
6. **일정 취소** 후 알림의 **되돌리기**로 복원할 수 있습니다. 알림은 10초간 유지되며 키보드로 조작 중에는 사라지지 않습니다.
7. 모바일 캘린더는 날짜별 점으로 상담을 표시합니다. 캘린더 아래 **선택한 날짜의 일정 보기** 버튼으로 상세 목록에 바로 이동합니다.
8. 키보드로 날짜에 진입한 뒤 방향키로 날짜·주, Home/End로 주의 처음·끝, Page Up/Down으로 월을 이동합니다.

## 데이터 범위

- 모든 인물, 대화 이력, 일정과 분석은 가상 데이터입니다. 실제 AI, 진단, 로그인, 예약·알림 전송은 구현하지 않았습니다.
- 입력 내용과 일정 변경은 해당 탭의 메모리에만 유지되며 새로고침하거나 닫으면 초기화됩니다. LocalStorage·쿠키·외부 분석 도구를 사용하지 않습니다.
- 두 전용 페이지는 독립된 데모입니다. 내담자 페이지의 공유 동의나 메모가 별도 상담사 페이지로 전송·동기화되지는 않습니다. 상담사 화면은 미리 구성한 샘플 동의 상태를 표시합니다.
- 리포트에는 전체 대화나 일기 원문을 포함하지 않습니다. 감정 점수는 자기보고 기분 UI이며 의학적 척도가 아닙니다.
- 시스템 글꼴을 사용하며 외부 웹 폰트를 요청하지 않습니다.

## 파일과 검증

이번 UI/UX 수정에는 지정된 Apple Design 스킬의 화면 위치 안내, 즉각적인 조작 피드백, 반투명 상단바, 시스템 글꼴과 접근성 지침을 적용했습니다. 내담자 공간은 라벤더, 상담사 공간은 세이지 색상으로 구분합니다. 모션·투명도 감소와 대비 증가 설정도 지원합니다. 구체적인 적용 근거는 [UI_REVIEW.md](UI_REVIEW.md)에 정리했습니다.

- `index.html`, `client.html`, `counselor.html`: 역할별 진입점과 접근성 기본 구조
- `app.js`: 역할별 경로, 화면, 일정 관리와 탭 내 상태
- `styles.css`: 역할별 색상, 캘린더, 반응형, 접근성·인쇄 스타일
- `assets/mind-garden.svg`: 내담자 화면의 로컬 벡터 일러스트
- `UI_REVIEW.md`: 지정 디자인 스킬의 적용 내역과 실제 검증 결과

브라우저 검증은 `python scripts/verify_ui.py`로 실행합니다. 설치된 Chrome/Chromium 또는 Windows Edge와 Python의 `websocket-client` 또는 `websockets` 패키지가 필요합니다. `BROWSER` 환경 변수로 브라우저 실행 파일을 지정할 수 있습니다. 스크린샷은 Git에서 제외되는 `artifacts/`에 저장됩니다. 앱 자체에는 이 검증 의존성이 필요하지 않습니다.

2026년 11월 12일 로컬 Chrome에서 81개 검증 항목이 통과했습니다. 역할별 경로 분리, 일정 추가·수정·취소·복원, 시간 중복 방지, 윤년 날짜 이동, 모바일 레이아웃과 키보드 접근성을 확인했습니다.
