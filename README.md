# 마음결 · 웹 UI MVP

심리 상담을 시작하기 전, 내담자가 AI와 감정을 정리하고 동의한 리포트로 상담사와 연결되는 프런트엔드 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. Node.js, 패키지 설치, 백엔드가 필요하지 않습니다.

로컬 HTTP 서버를 선호한다면 프로젝트 폴더에서 다음 명령을 실행하세요.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173`에 접속합니다. 종료하려면 터미널에서 `Ctrl+C`를 누르세요.

## 체험 흐름

1. **마음 홈**에서 오늘의 감정을 선택합니다. 주간 그래프에 즉시 반영됩니다.
2. **마음 대화**에서 메시지를 보냅니다. 주제에 따라 준비된 응답 예시가 표시됩니다. Enter는 전송, Shift+Enter는 줄바꿈입니다.
3. **감정 기록**에서 짧은 일기를 작성합니다. 추가한 기록을 삭제할 수도 있습니다.
4. **나의 마음 리포트**에서 가상 대화 분석을 확인하고, 상담사에게 전할 메모를 저장합니다.
5. 공유 항목을 확인하고 체크박스로 동의합니다. 동의는 개인정보 설정에서 철회할 수 있습니다.
6. 상단의 **상담사 공간**으로 전환합니다. 동의 전 잠겨 있던 서연님의 리포트가 열립니다.
7. 이름·주제로 내담자를 검색하고, 리포트와 상담 준비 메모를 확인합니다. 예시 일정을 선택하거나 취소할 수 있습니다.
8. 리포트의 **인쇄 / PDF 저장**을 누르면 리포트만 출력하는 브라우저 인쇄 화면이 열립니다.

## 범위와 데이터

- 모든 인물, 대화 이력, 상담 일정, 분석 내용은 제품 설명을 위한 가상 데이터입니다.
- 실제 AI 모델, 임상 검사, 진단, 위험도 평가, 로그인, 예약, 리포트 전송은 구현하지 않았습니다.
- 사용자가 입력한 내용은 현재 탭의 메모리에만 유지됩니다. 새로고침하거나 탭을 닫으면 초기화됩니다. LocalStorage·쿠키·외부 분석 도구를 사용하지 않습니다.
- 감정 점수는 자기보고 기분을 1~5점으로 나타낸 UI입니다. 의학적 척도가 아닙니다.
- 상담사에게 표시하는 리포트는 가상 대화 요약, 예시 발췌, 감정 추이, 직접 저장한 전달 메모로 구성됩니다. 새로 입력한 전체 대화와 일기 원문은 포함되지 않습니다.
- Google Fonts의 Noto Sans KR을 불러옵니다. 오프라인에서는 시스템 글꼴로 대체하며 핵심 기능은 동일하게 동작합니다.

## 구성

- `index.html`: 진입점, 페이지 메타 정보, 접근성 기본 구조
- `styles.css`: 라벤더 기반 디자인, 반응형, 포커스, 모션 감소, 인쇄 스타일
- `app.js`: 화면 렌더링, 탭 내 상태, 샘플 응답, 공유 동의 및 체험 기능
- `assets/mind-garden.svg`: 로컬 벡터 일러스트

웹 UI는 전역 `AGENTS.md`와 `emil-design-eng` 스킬에 따라 구성했습니다. 다음 개발 단계에서 실제 AI 응답, 보안·동의 관리, 계정, 서버 저장, 상담사 권한 검증과 연결할 수 있습니다.

## 개발 검증

`UI_REVIEW.md`에 디자인·접근성 검토와 브라우저 검증 범위를 정리했습니다. 검증용 `scripts/verify_ui.py`는 로컬 Microsoft Edge와 Python의 `websocket-client` 패키지를 사용하며, 앱 실행에는 이 의존성이 필요하지 않습니다. 검증 결과물은 Git에서 제외되는 `artifacts/`에 저장됩니다.
